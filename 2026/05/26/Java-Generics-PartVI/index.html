类型实参

关于类型实参存在一些规则：

  • 类型实参的类型可以是引用类型、通配符或参数化类型
  • 但对于泛型方法来说，不允许通配符作为类型实参
  • 类型参数也可以作为类型实参
  • 基本类型不允许作为类型实参
  • 类型实参必须符合类型参数边界

上述规则，许多在前些章节中多少提到过。基本类型无法作为类型实参，因为其不属于 Object 类的子类，无法进行泛型擦除。有界/无界通配符实例化的具体规则也在 Java-Generics-PartIII 中有详细描述。

泛型类的类型参数，可以作为类型实参，传入另一个泛型类。

多通配符

当多个通配符同时出现在多个类型实参上，每个通配符相互独立，可以表示不同的类型。

边界

边界出现在有界通配符和类型参数边界中，容易混淆，在此理清两者的场景和限制。

一个通配符只能有一个边界，而一个类型参数可以有多个边界。通配符可以有一个下界或一个上界，而类型参数没有下界。
